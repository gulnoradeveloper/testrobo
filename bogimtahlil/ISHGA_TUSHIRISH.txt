BO'G'IMTAHLIL 1.0 - ISHGA TUSHIRISH
====================================

Talab: Python 3.11 yoki 3.12  (https://www.python.org/downloads/)
       O'rnatishda "Add python.exe to PATH" belgisini albatta qo'ying.
       Node.js va boshqa dasturlar SHART EMAS. Birinchi ishga tushirishda internet kerak.

WINDOWS
  0. Avvalgi nusxalarning BARCHA qora oynalarini yoping (eski server ishlab tursa, eski versiya ochiladi).
  1. ZIP faylni YANGI papkaga oching (eski papkaga nusxalash shart emas).
  2. bogimtahlil papkasidagi  BOGIMTAHLIL.bat  faylini ikki marta bosing. U o'zi:
       - virtual muhit va asosiy kutubxonalarni o'rnatadi (1-5 daqiqa);
       - artifacts\model.pt borligi uchun sun'iy intellekt kutubxonasini (PyTorch, ~250 MB, 3-10 daqiqa) o'rnatadi;
       - serverni ishga tushirib, brauzerni ochadi.
  3. Oynada "Dastur papkasi" va "Model fayli: ... MB" qatorlarini tekshiring - model fayli BOR bo'lishi kerak.
  4. Qora oynani YOPMANG - dastur shu oynada ishlaydi.
  Sinash: "Rentgen tahlili" sahifasida demo_images papkasidagi tasvirlarni yuklang
  (fayl nomidagi KL - mutaxassis bahosi, model natijasi bilan solishtirish uchun).

LINUX / macOS
  ./start.sh

MUAMMO BO'LSA
  - DIAGNOSTIKA.bat ni ishga tushiring - logs\diagnostika.txt fayli Notepad'da ochiladi. Shu faylni yuboring.
  - Qora oynadagi xabarni yoki logs\start.log, logs\server.log, logs\ai_install.log fayllarini yuboring.
  - "Python topilmadi": Python'ni "Add python.exe to PATH" bilan qayta o'rnating.
  - PyTorch o'rnatilmasa (Python 3.14 bilan bo'lishi mumkin): Python 3.12 ni o'rnating, .venv papkasini o'chiring,
    BOGIMTAHLIL.bat ni qayta ishga tushiring.
  - Port band bo'lsa, dastur keyingi bo'sh portni o'zi tanlaydi (manzil oynada ko'rsatiladi).
